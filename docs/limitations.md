# 技术边界与开放项

个人单机毕业设计，不宣称QPS、线上可用性、多实例强一致或Exactly Once。

- MQ发布与MySQL事务没有Outbox补偿；DLQ保留失败消息但没有自动重放工具。
- Redis指标定时全量同步；磁盘图片及旧文件生命周期、本地文件存储、localStorage JWT均有适用边界。
- ONNX首次下载仍依赖外网；真实模型调用是可选且需要明确配置，测试关闭收费模型。
- AI写工具默认false并由服务端只读白名单过滤；若显式开启，现有ActionResult仍可能转述内部异常。该风险已识别，未在发布整理中扩大改造。
- E-R图只有category_follow.category_id为实际FK，其余服务端逻辑关系不能宣称数据库级级联或强制完整性。
- API时间已统一UTC，前端按上海时区展示；历史DATETIME字面值来源仍需核实，不能静默将旧截图日期当北京时间。
- HTTP错误沿用Result结构：明确业务拒绝保留稳定4xx，未知异常和5xx reason为固定安全提示；管理看板已移除宽泛异常转发。

后续改造需按具体需求独立立项，不在本候选增加业务功能或依赖。

- 本地聊天模式关闭全部模型工具，通过结构化来源声明与有效编号校验减少误引；它不是逐句语义证明，阅读时仍需核对原文。
- 额度是估算软限制，已有用量汇总模型字段可能为空；模型名可由轨迹步骤核对。模型审核、运营洞察可单独关闭，默认示例关闭。
- V25 / AI代码已在本轮远端CI通过完整数据库服务集合；本次没有部署到本机或公网，也没有新增浏览器／压力验收。具体提交与计数见[发布记录](updates/20261018.md)，不以CI成功宣称生产能力。
